Бұл нұсқа пайдаланушы жіберген интерфейс үлгісіне жақын стильде жасалды:

- сол жақ sidebar
- жоғарғы top bar
- үлкен home hero card
- 3 quick action card
- Topic Library модуль карточкалары
- Vocabulary / Listening / Reading / Use of English / Speaking бөлімдері
- Teacher Generator
- Teacher Dashboard
- My Progress
- Competition Mode
- About Project
